Este repositório foi criado para organizar e armazenar as atividades, os exercícios e os projetos desenvolvidos durante a matéria Boot Camp I. Seu objetivo é registrar meu aprendizado ao longo da disciplina, permitindo acompanhar minha evolução e manter todos os materiais em um só lugar.
Além disso, o repositório servirá como um espaço para colocar em prática os conhecimentos adquiridos durante as aulas e documentar cada etapa do meu desenvolvimento acadêmico.
